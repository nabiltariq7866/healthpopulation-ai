# HealthPopulation AI

Frontend-only population health and chronic disease intelligence product demo. All patient and integration data is deterministic and synthetic.

## Run

```bash
npm install
npm run dev
```

Verify with `npm test` and `npm run build`.

Start at Population Overview, open High Diabetes Risk, select Maria Collins, create outreach, assign a manager, schedule the review, and inspect the updated care-gap and audit views. The cardiovascular campaign in Outreach can be launched and its responses simulated. Administrator role enables deterministic demo reset.

No live EHR, messaging, AI API, clinical risk model, or patient data is used.
